Stack tecnológica

As tecnologias com que
trabalhamos.

Sem buzzwords. Estas são as ferramentas que usamos todos os dias para construir produtos que funcionam em produção.

HTML5

Frontend

A base de toda a interface. Escrevemos HTML semântico e acessível desde o primeiro elemento.

Desde o inícioSemântico · WCAG · SEO

CSS3

Frontend

Design systems, animações e layouts responsivos escritos à mão — sem frameworks desnecessários.

Desde o inícioCustom Properties · Grid · Animações

JavaScript

Frontend

Vanilla JS no frontend — sem dependências a mais. Interações rápidas, código que qualquer pessoa da equipe entende.

Desde o inícioES6+ · Web APIs · Performance

Python

Backend

O coração do backend. APIs, automações, processamento de dados e integrações — tudo em Python.

Stack principalAPIs REST · Automação · Integrações

MySQL

Base de Dados

Base de dados relacional para projetos que exigem consistência e estrutura. Schema claro, queries otimizadas.

Stack principalRelacional · Queries otimizadas · Backups

Node.js

Backend

Runtime JavaScript no servidor para APIs rápidas, serviços em tempo real e ferramentas de linha de comando.

Stack principalAPIs · WebSockets · CLI

PostgreSQL

Base de Dados

Base de dados relacional avançada para projetos que exigem transações complexas, JSON nativo e alta confiabilidade.

Stack principalRelacional · JSON · Alta disponibilidade

MongoDB

Base de Dados

Base de dados orientada a documentos para projetos com estruturas flexíveis, escalabilidade horizontal e dados não relacionais.

Quando faz sentidoNoSQL · Documentos · Escalável

Quando um projeto exige uma ferramenta diferente, avaliamos e adoptamos — mas sem modas. Cada escolha técnica tem de justificar-se com resultados reais.
